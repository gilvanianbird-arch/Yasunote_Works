About

理学療法士として10年以上、一般病棟から回復期リハビリ病棟まで幅広く勤務しながら、独学でWebエンジニアリングを習得。 「現場を知るエンジニア」という唯一の立ち位置から、要件定義・設計・実装までを一気通貫で担います。 また、HTML/CSS/JavaScriptを用いた医療・ヘルスケア特化のLP制作も得意としており、患者目線の導線設計が強みです。

臨床専門

理学療法士として10年以上、一般病棟・回復期リハビリテーション病棟など多様な現場に従事。FIM評価・退院支援・カンファレンス運営など幅広い病棟業務を熟知。

技術スタック

Next.js / TypeScript / Supabase / Tailwind CSS / Vercel。HTML/CSS/JSによるLP制作から実務レベルのWebアプリ開発まで対応。

ポジショニング

医療ドメイン知識 × ソフトウェア開発力という希少な掛け合わせにより、「何を作ればいいか」から「どう作るか」まで一人でカバー。医療系SaaSや業務効率化ツール開発において、要件のすり合わせコストを大幅に削減します。
